This page drives a simulated car through its control API, and none was found. Start one with either command — the first is the usual one:

python web/app.py --adapter sim --port 5055
python hakake_sim.py --pty --scenario drive --launch-dashboard

Both print the dashboard, cockpit and control-API URLs. A rig on an unusual port can be named directly: /sim?control=http://127.0.0.1:PORT.
